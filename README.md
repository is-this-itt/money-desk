# Money Desk

A private spending dashboard for Indian bank and credit card statements. It runs only on your own
computer: statements are read locally, and data is saved to a file next to the app.

Every change arrives as a pull request and gets two independent automated reviews before the
owner merges it: a security review (`.github/security-review-instructions.md`) and a code review
for correctness, tests and UI consistency (`.github/code-review-instructions.md`).
